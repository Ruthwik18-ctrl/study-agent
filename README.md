# Study Agent

A beginner-friendly AI-style study assistant built with Python and Streamlit. It explains topics in simple language and creates practice questions using a small built-in topic library.

## Features
- Choose a subject and topic
- Read a simple explanation
- View key points and a quick example
- Take a short multiple-choice quiz
- Runs locally; no API key required

## Requirements
- Python 3.10 or newer
- Internet connection for the first-time package installation

## Run locally
```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
streamlit run app.py
```
